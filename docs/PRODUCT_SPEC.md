# Pawket Product Spec

## What Pawket is

Pawket is a mobile-first virtual pet game for Solana Mobile. Each pet is a living on-chain companion with an evolving Pet Passport: care history, personality, level, achievements, badges, seasonal memories, and collectible items.

## Core user loop

1. Connect wallet on devnet.
2. Adopt a first Pawket.
3. Care through feeding, playing, grooming, and resting.
4. Earn XP, streaks, memories, and visual progression.
5. Visit friends and join seasonal community events.
6. Collect cosmetics and event rewards.

## Why Solana makes sense

Solana enables low-cost, fast, mobile-friendly ownership records for pet identity, passport milestones, item ownership, and payment settlement without custodial accounts.

## MVP scope

- Wallet connection abstraction.
- Adopt one pet per wallet initially.
- Care actions with cooldowns and XP.
- Pet Passport events.
- Devnet Anchor program.
- API persistence for profile, richer history, items, and payment intents.
- Polished mobile starter UI.

## Non-MVP scope

- Open marketplace.
- Breeding/evolution economy.
- Fiat production on-ramp.
- Real-time multiplayer spaces.
- Mainnet launch.

## Monetization

Premium eggs, cosmetics, event passes, and item bundles. Purchases should settle in SOL or USDC. Jupiter can later route other tokens to preferred settlement assets. Mercuryo can later onboard fiat users into SOL/USDC.

## Retention loops

Daily care streaks, evolving stats, seasonal event memories, achievements, and cosmetic unlocks.

## Social loops

Visit friends, leave care boosts, show passport badges, seasonal community goals, and optional public pet profiles.

## Seasonal events

Time-bounded events with quests, badges, item drops, and collective milestones. Season One should validate core retention without complex economy risk.

## Risks

- Wallet/signing UX friction.
- Botting care actions and rewards.
- Over-financializing a companion game.
- Payment/webhook fraud.
- On-chain account bloat.
- Mobile native dependency complexity.
