# Pawket — Design (landing)

One page. One headline, one action, real product art. Nothing that doesn't
exist yet.

## World

Dark ink-plum canvas (`#0b0916`) with faint indigo/ember/sky glows; one
accent — firefly amber (`amber-300`) — for the primary action, the eyebrow,
and the companion's glow. Slate text scale otherwise. No gradients on text.

## Signature

Three companion portraits (real `PetAvatar` renders: Luna cat radiant, Moss
pup happy, Cloud bun okay). The center portrait breathes (`den-breathe`,
5s glow pulse). That is the only animation on the page.

## Rules

- Sans display, tight tracking, `text-4xl sm:text-6xl`. Emphasis in the same
  family (italic `lives`), never a mixed serif word.
- One eyebrow on the page (hero). Section headlines stand alone.
- Ritual is a hairline-divided row, not cards. One radius family (20px
  surfaces, full pills for meta/actions).
- Copy is sparse and honest: what exists (browser companions, daily ritual),
  one forward line in the footer (on-chain tomorrow). No stats, no claims.
- `prefers-reduced-motion` collapses all animation globally. Focus always
  visible (amber outline). Single theme — dark, locked.
